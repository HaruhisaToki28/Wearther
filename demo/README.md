# Wearther デモ画面

Weartherアプリの主要画面をHTML/CSSで作成したデモです。機能は実装されておらず、見た目のみのデモです。

## ファイル構成

- `index.html` - メインのHTMLファイル（4つの画面を含む）
- `styles.css` - スタイルシート
- `script.js` - 画面切り替えなどの簡単なインタラクション

## 含まれる画面

1. **ホーム画面** - ストーリー一覧、天気カード、AIコーデ提案
2. **タイムライン画面** - コーデ投稿一覧、フィルタータブ
3. **詳細天気画面** - 天気情報の詳細表示、期間切替
4. **プロフィール画面** - ユーザープロフィール、投稿一覧

## 使い方

1. `index.html`をブラウザで開く
2. 下部のタブバーで画面を切り替え
3. ストーリー、フィルタータブ、期間タブなどもクリック可能

## デザインの特徴

- iOS風のモダンなデザイン
- グラデーションを活用したおしゃれな配色
- レスポンシブ対応（iPhoneサイズを想定）
- 天気×ファッションアプリらしい見た目

## 注意事項

- これはデモ画面であり、実際の機能は実装されていません
- データは静的に記述されており、実際のAPI連携はありません
- ブラウザで直接開いて動作確認できます
